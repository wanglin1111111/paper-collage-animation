# paper-collage-animation · 纸艺拼贴科普动画

> **命题**：一个科普主题 → 一套可执行的纸片拼贴动画创作方案。
> 把抽象的科普概念，翻译成"纯色背景 + 纸片动态"的视觉语言——观众 30 秒看懂一个机制，还觉得好看。

输入一个科普主题（如"为什么冬天会静电""黑洞是怎么形成的"），产出一套可直接拿去制作的完整创作方案：趣味开场钩子、口语化口播文案、视觉隐喻设计、分镜/关键帧表（含提示词）、制作指引与自检清单。

本 Skill 沉淀自对主流 AI 纸艺拼贴动画工具的横向实测：**纯色背景打底 + 首帧过渡到关键帧**提升画面流畅度，**一帧一动作**保证生成稳定。

---

## 它能做什么

| 输入 | 输出（7 部分，一次性完整产出） |
|---|---|
| 一个科普主题词/一句话 | ① 趣味开场钩子（反差/悬念/热点意象） |
| （可选附：平台、时长，缺省自动判断） | ② 口语化口播文案（每 5-8 秒一个信息点） |
| | ③ 视觉隐喻设计（抽象概念 → 具象纸片意象） |
| | ④ 分镜/关键帧表（逐镜头：画面+文案+提示词+转场） |
| | ⑤ 纸片动画提示词规范（纯色背景 + 动态帧生成） |
| | ⑥ 制作指引（含首帧纯色过渡技巧） |
| | ⑦ 自检清单 |

## 两条硬约束

1. **科普准确性**：确定的常识直接写；具体数字要么核实、要么模糊表述（"大约/数倍/量级"）、要么标注「待核实」。禁止为效果编造精确数据。
2. **纯色背景 + 首帧过渡**：每个场景提示词必须带纯色背景规范；每个场景首帧为纯色背景、第二帧过渡到关键帧。实测验证的流畅度核心手法，不可省略。

## 自适应定档

| 主题类型 | 总时长 | 镜头数 | 例 |
|---|---|---|---|
| 单点冷知识（默认） | 30-60 秒 | 5-8 | 为什么冬天会静电 |
| 因果链/多步过程 | 60-90 秒 | 8-10 | 黑洞是怎么形成的 |
| 单一反常识结论 | 15-30 秒 | 3-5 | 蜂蜜永远不会变质 |

## 使用

遵循 [Agent Skills 开放标准](https://agentskills.io/specification)。把本仓库克隆/复制到你环境的 skills 目录即可（如 `~/.agents/skills/paper-collage-animation/`）：

```bash
git clone https://github.com/wanglin1111111/paper-collage-animation.git \
  ~/.agents/skills/paper-collage-animation
```

之后在对话里直接说「帮我做一期"为什么冬天会静电"的科普动画」即可触发。

产出为文本方案；用 `scripts/validate.py <方案文件>` 可对产出做格式校验（启发式，隐喻质量与事实准确性仍需人工复核）。

## 工具适配

提示词为通用规范，适配任意图像/视频生成工具。若你使用特定工作流（如三步流程类、开源纸片篓类），按其提示词语法改写五段内容即可——但**纯色背景**与**首帧过渡**两条核心保留。
