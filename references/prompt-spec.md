# 提示词规范 (prompt-spec)

关键帧/动态帧提示词的通用写法。目标：用户拿去任何图像/视频生成工具，都能稳定出"纸片拼贴"风格。

> 什么时候读：生成分镜表第 6 步，写每条关键帧提示词前。

## 一、提示词五段结构（通用规范）

```
[风格前缀] + [背景规范] + [主体描述] + [动作/状态] + [禁止项]
```

| 段 | 内容 | 例 |
|---|---|---|
| 风格前缀 | 全片统一，一字不改 | 纸艺拼贴风格，剪纸质感，硬边投影 |
| 背景规范 | 纯色 + 具体色名 | 纯米白色背景，无渐变无纹理 |
| 主体描述 | 具象纸片元素，有形状有颜色 | 一只红色气球形状的剪纸 |
| 动作/状态 | **一个**动作或状态 | 轻微向左摆动 |
| 禁止项 | 排除生成工具的常见跑偏 | 无文字，无照片元素，无3D渲染感 |

**完整示例**：
> 纸艺拼贴风格，剪纸质感，硬边投影。纯米白色背景，无渐变无纹理。一只红色气球形状的剪纸，下方系着一根细线，线尾贴着几片灰色小纸屑。气球轻微向左摆动，纸屑被微微吸起。无文字，无照片元素，无3D渲染感。

## 二、首帧过渡（强制手法）

每个场景（背景色变化或场景切换处）按"两帧式"处理：

```
首帧：纯色背景帧（该场景的底色，无主体或仅极简主体边缘）
  ↓ 过渡
第二帧：关键帧（主体完整弹入/滑入）
```

**为什么**：生成工具直接出"满画面"首帧容易构图跑偏、与上一场景衔接生硬；纯色首帧给工具一个干净的起点，转场自然，成片流畅度高。这是实测验证的核心手法，不可省略。

背景色变化时同理：新场景首帧 = 新的纯色背景（旧主体完全退出后），再过渡进新主体。

## 三、动态帧规则

- **一帧一动作**：一条提示词只描述一个动作。错误示例："小球弹起并旋转同时变红分裂"。拆成多帧。
- **动作幅度写小**：轻微摆动 > 剧烈翻滚；生成工具对"大动作"还原差。
- **主体数量克制**：单帧 ≤3 个主要纸片元素；群像（如 1000 张小纸片）用"重复排列的相同小纸片"描述。
- **帧间连续性**：相邻帧的主体位置/颜色只做增量变化，不要跳变——视频工具的插值才跟得上。

## 四、工具适配（可选附赠，不绑定）

通用规范为主，适配任何工具。若用户指定了某个具体工具/工作流（例如其测评中验证过的三步流程类工作流、开源纸片篓工作流等），按该工具的提示词语法**改写**以上五段内容，但两条核心不变：

1. 纯色背景规范保留；
2. 首帧过渡结构保留。

用户没提供某工具的具体语法时，不要臆造该工具的"专用参数"——交付出通用版并注明"可按你的工具语法微调"。

## 五、逐条自检

- [ ] 五段齐全（风格前缀/背景/主体/动作/禁止项）？
- [ ] 风格前缀与全片统一？
- [ ] 一帧一动作？
- [ ] 场景切换处有两帧式过渡设计？
- [ ] 没有臆造工具专用参数？
